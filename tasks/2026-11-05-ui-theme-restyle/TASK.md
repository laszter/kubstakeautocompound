### 2. กลไก theme (ต้องทำตามนี้เป๊ะ — RECON §C; ไม่ใช้ next-themes, ไม่มี inline script)
1. `apps/web/src/lib/theme.ts` (shared, **ห้าม** `server-only`/env import):
   ```ts
   export const THEMES = ["light", "dark", "system"] as const;
   export type Theme = (typeof THEMES)[number];
   export const DEFAULT_THEME: Theme = "system";
   export const THEME_COOKIE = "theme";
   export const THEME_COOKIE_MAX_AGE = 60 * 60 * 24 * 365;
   export const THEME_LABELS: Record<Theme, string> = { light: "สว่าง", dark: "มืด", system: "ตามระบบ" };
   /** keep in sync with --background in globals.css (used for <meta name="theme-color">) */
   export const THEME_COLORS = { light: "#FBFAFC", dark: "#0E1114" } as const;
   export function parseTheme(v: string | null | undefined): Theme; // whitelist → DEFAULT_THEME
   ```
2. `apps/web/src/lib/theme-server.ts`: `import "server-only"`, `export async function getTheme(): Promise<Theme> { return parseTheme((await cookies()).get(THEME_COOKIE)?.value); }`
3. `apps/web/src/app/layout.tsx` → `async` + `const theme = await getTheme()` → `<html lang="th" className={\`h-full antialiased ${theme}\`}>` (class อื่นคงไว้); เพิ่ม
   ```ts
   export async function generateViewport(): Promise<Viewport> {
     const theme = await getTheme();
     return {
       colorScheme: theme === "system" ? "light dark" : theme,
       themeColor: theme === "system"
         ? [{ media: "(prefers-color-scheme: light)", color: THEME_COLORS.light }, { media: "(prefers-color-scheme: dark)", color: THEME_COLORS.dark }]
         : THEME_COLORS[theme],
     };
   }
   ```
   (`metadata` static คงไว้; `cookies()` ทำให้ทุก route dynamic — ทุกหน้า dynamic อยู่แล้ว; `/api/health` ไม่ผ่าน layout) · **ไม่ต้องใส่ `suppressHydrationWarning`** (server render class จาก cookie = client first render) — ถ้า U7 เจอ hydration warning ให้ใส่เฉพาะบน `<html>`
4. `globals.css` — แทนบรรทัด `@custom-variant dark (...)` ด้วย block form:
   ```css
   @custom-variant dark {
     &:is(.dark, .dark *) { @slot; }
     @media (prefers-color-scheme: dark) { &:is(.system, .system *) { @slot; } }
   }
   :root { color-scheme: light; /* light tokens */ }
   :root.dark { color-scheme: dark; }
   :root.system { color-scheme: light dark; }
   :root { @variant dark { /* dark tokens เขียนครั้งเดียว */ } }
   .theme-switching, .theme-switching *, .theme-switching *::before, .theme-switching *::after { transition: none !important; }
   ```
   (`:is()` รักษา specificity ของ shadcn; **combo นี้ยังไม่เคยทดสอบ** → U1 ต้อง grep CSS ที่ build แล้ว; fallback = เขียน `.dark { … }` + `@media (prefers-color-scheme: dark) { .system { … } }` ซ้ำ 2 ชุด)
5. `apps/web/src/components/theme-toggle.tsx` (`"use client"`): `ThemeToggle({ initial: Theme; className?: string })` — `useState(initial)` (ค่ามาจาก server → ไม่ต้อง mounted guard/useEffect); UI = segmented pill 3 ปุ่ม icon (`SunIcon`/`MoonIcon`/`MonitorIcon`) `role="radiogroup" aria-label="ธีม"`, แต่ละปุ่ม `role="radio" aria-checked` + `title` + `<span className="sr-only">` = `THEME_LABELS`; selected = `bg-primary/10 text-primary` (ไม่ใช่ solid); `apply(next)`:
   ```ts
   const root = document.documentElement;
   root.classList.add("theme-switching");
   root.classList.remove(...THEMES); root.classList.add(next);           // ห้าม overwrite className
   document.cookie = `${THEME_COOKIE}=${next}; Path=/; Max-Age=${THEME_COOKIE_MAX_AGE}; SameSite=Lax${location.protocol === "https:" ? "; Secure" : ""}`;
   void root.offsetHeight;                                                 // flush styles
   setTimeout(() => root.classList.remove("theme-switching"), 0);
   setTheme(next);
   ```
   cookie ไม่ httpOnly (client เขียน) — server whitelist ด้วย `parseTheme` เสมอ · วางใน header ของ `(app)/layout.tsx` และมุมขวาบนของ `/login`
