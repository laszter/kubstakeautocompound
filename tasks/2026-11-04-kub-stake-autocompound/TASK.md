### Compound policy (ต้องทำตามเป๊ะ — pure math อยู่ใน `packages/core/src/compound/` + unit tests)
- Reward = ค่าธรรมเนียม tx เท่านั้น, accrue ทุก block, **APR ≈ 0.58% (ผันผวน) → วัดสดด้วย EWMA ห้าม hard-code** (ค่าเริ่มต้นก่อนมี sample = 0.0058/ปี)
- Loss rate `L(t)=C/t + P·r²·t/2` → `t* = √(2C/(P·r²))`, **`R* = √(2·C·P)`** (ไม่ขึ้นกับ r) · compound คุ้มกว่าไม่ compound (1 ปี) เมื่อ `P > 8C/r²` ≈ 1,230 KUB (1-tx) / 1,790 KUB (2-tx)
- BigInt wei: `C = gasPrice × GAS_EST` (`GAS_EST_1TX = 210_000n`, `GAS_EST_2TX = 301_000n`, `GAS_EST_CLAIM = 110_000n` — expected gasUsed ไม่ใช่ limit) · `P = balanceOf` · `R = getLiquidRewards` · `R_star = isqrt(2n·C·P)` · `doCompound = R >= max(R_star, R_FLOOR) && gasPrice <= MAX_GAS_PRICE && now − lastCompound >= MIN_INTERVAL` · `r_est = EWMA((R_now − R_prev)/(P·dt))` เฉพาะช่วงที่ไม่มี tx คั่น · `t_next = max(0, R_star − R)/(P·r_est)` (ETA แสดงใน UI + กำหนด next check) · next check = `clamp(t_next/4, CHECK_MIN_SEC, CHECK_MAX_SEC)`
- Worked example (1-tx, r=0.58%, C=0.005184 KUB): P=1,000 → R*=3.22, t*≈203 วัน; P=10,000 → R*=10.18, t*≈64 วัน; P=100,000 → R*=32.2, t*≈20 วัน
- Path: prefer 1-tx (`liquid − reserve − C_1tx ≥ pending`) → else 2-tx (`liquid − reserve ≥ C_2tx`) → else skip `insufficient_gas` · ใช้ C ของ path ที่เลือกจริง · validator `delegation=false|paused|isOfficialPool|status!=1` → **claim-only mode** (threshold = R* ที่ C = C_claim) + แจ้งเตือนใน UI
- **Trigger modes ต่อ position (user เลือกใน UI; user decision 2026-11-04):**
  1. `optimal` (default/แนะนำ) — trigger เมื่อ `R ≥ max(R*, R_FLOOR)` ตามสูตรข้างบน
  2. `threshold` — trigger เมื่อ `R ≥ threshold_wei` ที่ user ตั้ง (KUB); next check ใช้ ETA ถึง threshold แทน R*
  3. `schedule` — trigger ตามเวลา: เก็บเป็น cron expression `cron_expr` (5 ฟิลด์) + timezone `APP_TIMEZONE` (default `Asia/Bangkok`); worker คำนวณ `next_run_at = new Cron(expr,{timezone}).nextRun()` (croner 11); UI มี preset: ทุก N ชั่วโมง (`0 */N * * *`), ทุก N วัน เวลา HH:mm (`mm HH */N * *`), ทุกวัน HH:mm (`mm HH * * *`), ทุกสัปดาห์ วัน<d> HH:mm (`mm HH * * d`), หรือ custom cron; **ระยะห่างขั้นต่ำ ≥ 1h** (validate ด้วย `nextRuns(5)` ทุกคู่ต้องห่าง ≥ 3600s); guard เพิ่ม `min_reward_wei` (optional; default = `2 × C ของ path ที่เลือก`) → ถ้า pending < min_reward ตอนถึงเวลา = **`skipped` reason `dust_reward`** (ไม่ใช่ failed) แล้วเลื่อน `next_run_at` ไปรอบถัดไป
  - **ทุก mode** ยังผ่าน guards ชุดเดียวกัน: gas reserve, max gas price (skip แล้วลองรอบหน้า), min interval, pre-flight simulation, delegation-disabled → claim-only + alert, ไม่ส่ง value=0, path 1-tx/2-tx เหมือนกัน
  - UI แสดง R* + ETA เป็น hint ข้างทุก mode เพื่อให้ user เทียบ, แสดง mode ที่ active + parameter, next check (`next_check_at`) / next run (`next_run_at` เฉพาะ schedule), และ `last_run_result` ของรอบล่าสุด
- Guards: gas reserve ≥ 0.05 KUB ไม่เคยถูก stake; MAX_GAS_PRICE 50 gwei (engine skip รอบนั้น; manual action จาก UI ไม่ติด guard นี้); MIN_INTERVAL ≥ 1h; backoff หลัง revert = `min(2^level × 15min, 24h)`; ไม่ส่ง value=0; simulate (`estimateGas`) tx เดียวกันก่อนเซ็นเสมอ; verify receipt `status==='success'` + decode `Delegated`/`ClaimedRewards`/`Undelegated` logs จาก share address
- UI warning เมื่อ `P < 1,200 KUB` หรือ `t* > 180 วัน`: "ยัง auto-compound ไม่คุ้ม (ค่า gas ใกล้เคียงกำไร)"

### Security model (บังคับ)
- `MASTER_KEY` = base64 ของ 32 bytes; assert ความยาวตอน boot (web + worker) ไม่ผ่าน = refuse to start
- AES-256-GCM: IV 12 bytes สุ่มใหม่ทุกครั้ง, tag 16 bytes, **AAD = address (lowercase)**, เก็บ string `v1:<iv b64>:<tag b64>:<ct b64>`; derive address ด้วย `privateKeyToAccount` ตอน import; เก็บ address plaintext
- Web **encrypt-only** ตอน import; worker เท่านั้นที่ `decryptPrivateKey`; ไฟล์ที่แตะ key ใน web ใช้ `import 'server-only'`; ไม่มี `NEXT_PUBLIC_*` ใด ๆ; server action ไม่ return key/ciphertext
- `requireSession()` ภายใน**ทุก** server action และ route handler (ไม่พึ่ง proxy.ts อย่างเดียว); iron-session cookie httpOnly, sameSite `lax`, TTL `SESSION_TTL_SEC` (default 43200), `secure` จาก `COOKIE_SECURE` (default false)
- Login: เทียบด้วย `@node-rs/argon2` `verify(hashOfAdminPasswordComputedAtBoot, input)`; rate limit 5 ครั้งล้มเหลว/15 นาที/IP (ตาราง `login_attempts`)
- pino redact paths: `['privateKey','*.privateKey','encryptedKey','*.encryptedKey','password','*.password','masterKey','MASTER_KEY','req.headers.cookie','req.headers.authorization']`
- Web bind `${WEB_BIND:-127.0.0.1}`; Postgres ไม่ publish; containers รันเป็น `USER node`; `.dockerignore` มี `.env*`, `node_modules`, `.next`, `dist`; ไม่มี secret ใน build args
- Chain safety: assert `getChainId()===96` ก่อนเซ็น; explicit nonce `getTransactionCount({blockTag:'pending'})`; persist `txs` row (hash + signed raw) **ก่อน** `sendRawTransaction`; restart แล้วรอ receipt แทนการส่งซ้ำ; ไม่ stake จน balance หมด (reserve)

**Worker tx state machine (`apps/worker/src/txManager.ts`)** — ต่อ 1 tx: `prepare` (อ่าน nonce pending, gasPrice, estimateGas → gasLimitFor) → `simulate` (viem `call`/`estimateGas` เป็นตัว simulate; revert → throw ไม่สร้างแถว) → `sign` (`account.signTransaction({type:'legacy', chainId:96, nonce, gasPrice, gas, to, value, data})` → hash = `keccak256(raw)`) → **insert `txs` status `signed` (hash, signed_raw, nonce)** → `sendRawTransaction` → update `broadcast` → `waitForTransactionReceipt({hash, timeout: 180_000, pollingInterval: 3000})` → decode events → `confirmed` | `reverted`. **Recovery ตอน start / ต้นทุก tick:** แถว `signed` → re-send raw (ถ้า nonce ถูกใช้โดย hash อื่น → `failed:'nonce_consumed'`); แถว `broadcast` → รอ receipt (ถ้า > 10 นาทีและ nonce ถูกใช้แล้ว → `failed:'dropped'`; ถ้า nonce ยังไม่ถูกใช้ → re-send raw). ทำ tx **ทีละ 1 ทั้ง process** (ไม่ต้องกัน nonce ชน). `DRY_RUN=true`: หยุดหลัง `simulate` คืน `{ dryRun:true, gasEstimate }` ไม่ insert `txs`

**Action lifecycle (`apps/worker/src/executor.ts`)**: เลือก `actions` `status='pending'` `ORDER BY created_at` `FOR UPDATE SKIP LOCKED` ทีละแถว → `running` → ทำ: `delegate` (ตรวจ validator flags สด + `liquid − reserve ≥ amount + C`; amount + principal ≥ minDelegated) / `undelegate` (amount ≤ principal) / `claim` / `compound` (เรียก engine บังคับ ไม่สน threshold/mode/min_interval แต่ยังเคารพ reserve+simulation; ไม่สน max gas price) / `sync_validators` → `done` (+ `tx_id`) | `failed` (+ `error` สั้น ๆ อ่านรู้เรื่อง เช่น revert reason) | `skipped`. DRY_RUN → `done` + `error='DRY_RUN: simulated only (gas ≈ N)'`
